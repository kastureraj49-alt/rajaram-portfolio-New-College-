# Rajaram Kasture Portfolio

Responsive white-and-green portfolio built using HTML, CSS and JavaScript.

## Run in VS Code
1. Extract the ZIP.
2. Open VS Code → File → Open Folder.
3. Select `Rajaram_Kasture_Portfolio`.
4. Open `index.html`. For easier testing, install the Live Server extension, right-click `index.html`, and choose **Open with Live Server**. You can also open `index.html` directly in a browser.

## Personalize before publishing
Open `index.html` and replace:
- `your.email@example.com` with your email.
- `https://github.com/` with your GitHub profile URL.
- `https://www.linkedin.com/` with your LinkedIn profile URL.
Update skills and project descriptions to reflect your real experience. The Security Learning Lab is marked as a planned project, not a completed one.

## Deploy free with GitHub Pages
1. Sign in at https://github.com/
2. Click **+ → New repository**.
3. Name it `rajaram-portfolio`, choose **Public**, and create it.
4. In the repository click **Add file → Upload files**.
5. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder. Upload the files themselves so `index.html` is in the repository root.
6. Click **Commit changes**.
7. Open **Settings → Pages**.
8. Under Build and deployment, choose **Deploy from a branch**.
9. Choose branch `main` and folder `/ (root)`, then click **Save**.
10. Wait a few minutes and refresh the Pages screen. Open the URL shown there. It will usually look like `https://YOUR-USERNAME.github.io/rajaram-portfolio/`.

If it does not load, confirm that `index.html` is at the repository root and Pages is set to `main` / `(root)`. The Google Fonts link needs internet, but fallback fonts are included.
